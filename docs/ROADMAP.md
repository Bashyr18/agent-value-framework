# Roadmap

## 0.1 — architecture alpha

- ECAC math and break-even tools
- repository audit/doctor
- provider-neutral design
- Codex reference adapter
- compaction/state pattern
- skills governance
- OpenAI dated reference profile

## 0.2 — telemetry

- JSONL task telemetry helper
- route-level empirical ECAC reports
- acceptance/retry/escalation dashboards
- project task-class baselines

## 0.3 — adapters

- formal adapter contract
- additional coding-agent hosts
- runtime model/effort capability probes
- normalized hook/event surface where possible

## 0.4 — routing experiments

- offline policy simulation from historical tasks
- configurable Bayesian priors for sparse task classes
- confidence-aware escalation
- Pareto-front reports across quality, spend and latency

## Non-goals

AVF will not become a universal autonomous software-delivery platform. It should remain a thin economic/governance layer that composes with the project's own tools and coding-agent host.
