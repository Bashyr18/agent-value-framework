# OpenAI / Codex money-first reference profile

This is a dated starting profile, not a universal truth.

Normal-capacity economic core:

```text
Sol medium root → Luna max worker → deterministic gates
```

The profile's luna_worker role is also the provider-specific example for Luna Reserve. Reserve is runtime/account state, not a static entitlement in this file. Confirm it through the host, then checkpoint and reclassify remaining work.

Conditional lanes:

```text
Terra high reviewer    only when another probabilistic review is economically justified
Sol high rescue        when a bounded worker failure demonstrates more local reasoning is needed
Astra high adviser     only for unresolved high-leverage technical uncertainty
```

The `benchmark_snapshot.json` captures independent Codex-harness measurements available on 2026-09-05. Do not convert the index into project acceptance probability. Replace public priors with local ECAC telemetry as soon as enough tasks accumulate.

Reserve policy: safe bounded work may continue, conditional work requires a checkpointed contract and reclassification, and prohibited high-risk work pauses. Effective Luna alone is not proof of Reserve activation.
