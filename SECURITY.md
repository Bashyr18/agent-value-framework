# Security policy

AVF is an orchestration and economics framework, not a security boundary.

Provider hooks and agents can execute commands with the permissions granted by the coding-agent host. Do not treat AVF templates as a substitute for sandboxing, approvals, least privilege, secret management or organization policy.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. If GitHub private vulnerability reporting is enabled, use the repository's Security tab to submit it. Otherwise, contact the maintainers through a private channel associated with the repository; if no private channel is available, open a minimal issue requesting one without including sensitive details.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Give maintainers reasonable time to investigate and release a fix before public disclosure.
